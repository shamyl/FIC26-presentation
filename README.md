# FIC 2026 — Delivering Future-Ready Learning

Keynote by **Shamyl Bin Mansoor**, Co-Founder and Chief Technical Officer, LearnOBots.

The talk asks how future-ready learning can actually be delivered, and what LearnOBots has built to support it: curriculum, the LearnOSTEAM platform, makerspaces, FutureLabs, hardware kits, and teacher guidance.
